# 🏥 MediCare System

A full-stack MEAN (MongoDB, Express.js, Angular, Node.js) healthcare web portal featuring dedicated role-based portals for patients, doctors, and administrators.

[![Tech Stack](https://skillicons.dev/icons?i=angular,nodejs,express,mongodb,ts,js,html,css&theme=dark)](https://skillicons.dev)

</div>

---

### 🌟 Key Features

- **Role-Based Authentication:** Secure registration and login workflows with distinct views for Patients, Doctors, and Administrators.
- **Patient Dashboard & Booking:** Real-time appointment scheduling with doctor selection, date/time pickers, and reason for consultation tracking.
- **Doctor Workspace & Queue:** Active appointments queue, status updates (Confirmed, Completed, Cancelled), and direct prescription issuance.
- **Digital Prescriptions (Rx):** Seamless medical prescription creation including drug dosage, frequency, and clinical instructions.
- **Real-Time Metrics:** High-level dashboard cards tracking total consultations, completed sessions, pending requests, and patient volume.

---

### 🛠️ Tech Stack

- **Frontend:** Angular, TypeScript, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Architecture:** RESTful API Architecture / MEAN Stack
